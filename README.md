# Лабораторна робота №3
## Синтаксичний аналізатор на основі Lex/YACC

Синтаксичний аналізатор підмножини мови C, реалізований за допомогою Flex і Bison. Програма будує абстрактне синтаксичне дерево (AST), виконує обчислення та генерує код JavaScript. Для перегляду AST реалізовано візуалізацію у браузері засобами JavaScript і SVG.

## Можливості

- Функція `int main()` та тип `int`.
- Оголошення змінних, присвоєння та вкладені області видимості.
- Арифметичні операції `+`, `-`, `*`, `/`, `%`, унарний мінус і дужки.
- Порівняння `==`, `!=`, `<`, `>`, `<=`, `>=`.
- Логічні операції `&&`, `||`, `!` зі скороченим обчисленням для `&&` та `||`.
- Конструкції `if / else`, `while`, `return` і коментарі.
- Перевірка оголошень, ініціалізації змінних, ділення на нуль та переповнення.
- Експорт AST у JSON і генерація JavaScript та HTML для його запуску.

Обчислення виконуються зі знаковими 32-бітними цілими числами. Ділення відкидає дробову частину в напрямку нуля. Кількість кроків виконання обмежено для зупинки нескінченних циклів.

Реалізовано навчальну підмножину C: без препроцесора, масивів, вказівників, довільних функцій, `for`, `break`, `++` і дробових типів. Літерали є десятковими, зокрема з провідними нулями; їхній діапазон — від 0 до 2147483647.

## Вимоги

- Компілятор C із підтримкою C99.
- Make, Flex 2.6.4, Bison 2.3 або новіший.
- Сучасний браузер із підтримкою BigInt.
- Python 3 для автоматичних перевірок.
- Node.js — необов'язково, для автоматичного порівняння результатів JavaScript.

## Збирання та запуск

У папці репозиторію:

```bash
make
make demo
```

Очікуваний результат:

```text
Syntax: OK
Semantics: OK
Result: 15
Created: output/sum.ast.json, output/sum.js, output/sum.html
```

Запуск довільного прикладу:

```bash
mkdir -p output
./parser examples/condition.c output/condition
```

Другий аргумент задає префікс вихідних файлів. Без нього виконується лише перевірка й обчислення. Файли експортуються після успішного виконання; папка призначення має існувати.

## Генерація коду та візуалізація

На macOS відкрити результат виконання згенерованого JavaScript:

```bash
open output/sum.html
```

Відкрити сторінку AST:

```bash
open web/index.html
```

На сторінці вибрати файл `output/sum.ast.json`. Доступні масштабування, прокручування та перегляд даних вузла після натискання. Сторінка працює локально без сервера й зовнішніх бібліотек.

## Тестування

```bash
make test
```

Набір містить 36 перевірок синтаксису та семантики. За наявності Node.js також порівнюються результати виконання згенерованого JavaScript. Без Node.js цей етап пропускається.

Збирання, приклади, автоматичні перевірки, виконання JavaScript і візуалізацію AST перевірено на Intel Mac із Apple Clang 21.0.0, Flex 2.6.4 та Bison 2.3.

## Структура проєкту

| Файл або папка | Призначення |
| --- | --- |
| `lexer.l` | Правила лексичного аналізу |
| `parser.y` | Граматика LALR(1)-аналізатора та побудова AST |
| `ast.h`, `ast.c` | Структура дерева, керування пам'яттю, експорт JSON |
| `interpreter.c` | Перевірка імен і виконання AST |
| `codegen.c` | Генерація JavaScript |
| `main.c` | Запуск аналізатора та запис результатів |
| `Makefile` | Збирання, демонстрація та тестування |
| `examples/` | Коректні програми й приклади помилок |
| `tests/` | Автоматичні перевірки |
| `web/` | Візуалізація AST |

## Очищення

```bash
make clean
```

Команда видаляє виконуваний файл та файли, створені Flex і Bison. Вихідний код і результати в `output/` зберігаються.
